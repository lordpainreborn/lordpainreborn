## 🚀 Featured Showcase Project

### 📱 [All In One File Editor](https://github.com/lordpainreborn/all-in-one-file-editor) *(Proprietary / Closed-Source)*
> **A high-performance desktop forensic suite and binary partition manipulation workstation for Android firmware dumps.**

- **Architecture:** Electron 44 · React 19 · TypeScript · Vite · Node.js Buffer Streaming · Custom WebAudio Engine
- **Core Capabilities:**
  - 🔍 **Deadboot Forensic Inspection:** Decodes Vivo (`PD...` models & region), Oppo (`opporeserve2` display/OTA builds), and Xiaomi (`boot.f` fingerprints) directly from raw NAND partition dumps without booting.
  - 🛡️ **Automated Partition Patching:** AVB 2.0 / VBmeta disable flags, FRP hex reset, persist and modem patchers.
  - ⚡ **MTK Scatter Engine:** Generates SP Flash Tool v1.1.2 scatter configurations with UFS/eMMC auto-mapping.
  - 📦 **OFP Decryption & Repacking:** Decrypts official Oppo/Realme/OnePlus OFP firmware packages and repacks EROFS/EXT4 filesystems.
